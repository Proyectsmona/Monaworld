# VTuber Unified — Neon MVP

Frontend prototype in a neon pink / purple / black visual system.

Includes:
- Sidebar-style multi-section dashboard
- Overview / activity
- Overlay Studio 16:9
- Alerts
- Events & Actions
- Commands
- Music
- Stickers
- Rewards & Unified Coins
- Platforms
- Analytics
- Settings
- Single browser-source overlay URL for OBS
- Drag-and-drop overlay elements in the prototype

This is a visual MVP. Real OAuth, EventSub/Webhooks, TikTok bridge, backend WebSocket, database, payments and OBS integration still need implementation.
